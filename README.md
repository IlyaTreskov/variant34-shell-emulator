# Практическая работа №1. Вариант 34

Небольшой эмулятор UNIX-подобной командной строки на Python с графическим окном Tkinter. Программа выполняет команды в **виртуальной** файловой системе (VFS), загружаемой из XML. VFS изменяется только в памяти до команды `vfs-save`.

## Запуск на Windows

Откройте папку проекта в VS Code и выполните:

```bat
python main.py --vfs examples/demo.xml
```

Или запустите `run.bat`. Нужен Python 3 с поддержкой Tkinter, внешние библиотеки не нужны.

Для запуска стартовых команд:

```bat
python main.py --vfs examples/demo.xml --script examples/stage4.txt --debug-config
```

`--vfs` — путь к XML, `--script` — стартовый скрипт, `--debug-config` — вывод параметров запуска в терминал. Стартовый скрипт отображает ввод и результат в окне и останавливается на первой ошибке.

## Команды

- `ls [путь]` — показывает содержимое папки.
- `cd [путь]` — меняет текущую папку; `cd ..` — на уровень вверх.
- `head [-n число] файл` — первые строки текстового файла.
- `tac файл` — строки файла в обратном порядке.
- `history` — история команд.
- `mv откуда куда` — переименование или перемещение внутри VFS.
- `vfs-save путь.xml` — сохраняет VFS в XML.
- `exit` — закрывает окно.

Пример вручную в окне:

```text
ls /
cd /home/student
head -n 2 notes.txt
tac notes.txt
history
mv notes.txt newnotes.txt
ls
vfs-save saved-vfs.xml
```

## Проверка пяти этапов

1. **REPL:** окно, заголовок из имени пользователя и компьютера, разбор аргументов в кавычках, команды и ошибки.
2. **Конфигурация:** параметры запуска `--vfs`, `--script`, `--debug-config`, автоматическая остановка скрипта при ошибке. См. `scripts/01_config.bat`, `scripts/07_errors.bat`.
3. **VFS:** XML в памяти; двоичные данные описываются base64; проверка загрузки и `vfs-save`. См. `scripts/02_minimal.bat`, `scripts/04_deep.bat`, `scripts/08_wrong_xml.bat`.
4. **Основные команды:** `ls`, `cd`, `tac`, `head`, `history`. См. `scripts/05_commands.bat` и `examples/stage4.txt`.
5. **Дополнительная команда:** `mv`. См. `scripts/06_move.bat`, `examples/stage5.txt`.

Файлы в `scripts` можно запускать двойным щелчком в Windows. Скрипт `examples/errors.txt` специально содержит ошибку `cd /missing`: следующая команда не выполняется.

В задании первоначальные `ls` и `cd` на этапе 1 являются заглушками; в итоговой версии они уже настоящие команды этапа 4. История Git нужна, чтобы показать отдельные этапы разработки.

## Файлы проекта

- `main.py` — запуск, окно и стартовый скрипт.
- `shell.py` — разбор строки и выбор команды.
- `vfs.py` — XML, поиск каталогов, чтение и изменение VFS.
- `examples/` — XML и сценарии.
- `scripts/` — проверки запуска для Windows.
Историю Git посмотреть так:

```bat
git log --oneline --reverse
```

Для сдачи в СДО нужны публичная ссылка на репозиторий Git и PDF-версия README (открыть README на GitHub в браузере, затем Ctrl+P → «Сохранить как PDF»).

## Зачем нужны дополнительные файлы

- `examples/demo.xml`, `minimal.xml`, `deep.xml` — три варианта VFS по требованию этапа 3.
- `examples/bad.xml` — неверный XML для проверки обработки ошибки загрузки.
- `examples/quotes.txt` — аргументы команд в кавычках (этап 1–2).
- `examples/stage4.txt`, `stage5.txt`, `errors.txt` — сценарии команд и ошибок.
- `scripts/*.bat` — запуск разных вариантов программы и проверок Windows.
