1. Создай пустой PUBLIC репозиторий на GitHub, например:
   variant34-shell-emulator

2. Открой эту папку в VS Code и терминал.

3. Выполни:
   git init
   git branch -M main
   git remote add origin https://github.com/USERNAME/variant34-shell-emulator.git

4. Если преподавателю важны отдельные этапы разработки, делай коммиты по мере добавления файлов:
   feat(repl): implement GUI loop and quoted parser
   feat(config): add CLI options and startup scripts
   feat(vfs): add in-memory XML virtual file system
   feat(commands): implement ls cd tac head and history
   feat(vfs): implement in-memory mv command
   test(shell): add automated tests
   docs(readme): add project documentation

5. После коммитов:
   git push -u origin main

6. В СДО отправь ссылку на публичный репозиторий и PDF-версию README.md.
